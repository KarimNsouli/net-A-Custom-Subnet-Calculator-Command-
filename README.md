# net++-A-Custom-Subnet-Calculator-Command-
A custom subnet calculator command created in Bash 

While studying for my CCNA using Jeremy's IT lab, I stumbled upon the concept of "Subnetting" and I couldn't wrap my head around it, all those calculations and details just made it even more confusing so that's why I created net++, a custom subnet calculator command where a user puts in the IP address, the CIDR notation, and the Subnet Mask as input then it outputs the following:

Network Address, 
Broad-Cast Address, 
CIDR Notation, 
IP Class & Privacy Type, 
N. of Hosts in Subnet
Bit-Map of the IP Address 

using the host formula and the bitwise operations for both addresses. 

This project helped me sharpen my own Bash skills while also learning about what subnetting really is.
